# Общая биржа

Общая таблица цен NC Exchange (MTA:SA) для тебя и друзей и личный портфель для каждого.
Это веб-приложение (PWA): его можно установить значком на ПК и телефон.

- Цены, индексы и экономику видят все участники группы, обновления приходят сразу.
- Сделки, портфель и сигналы у каждого свои, другие их не видят.
- Цены можно вносить вручную или распознавать со скриншота планшета. Распознавание идёт на устройстве, игра не затрагивается.

Пока в `config.js` пусто, приложение работает в **демо-режиме**: всё хранится только в этом браузере.

## Запустить у себя

```bash
python -m http.server 8765 --bind 127.0.0.1
```

Потом открыть http://localhost:8765

## Шаг 1. Firebase (общее хранилище, бесплатно)

1. Зайди на https://console.firebase.google.com и нажми **Create a project**. Google Analytics можно выключить.
2. **Build → Authentication → Get started → Sign-in method → Google → Enable**, затем Save.
3. **Build → Firestore Database → Create database**. Регион выбери `eur3` (Европа), режим **production**.
4. Во вкладке **Rules** у Firestore замени весь текст содержимым файла `firestore.rules` и нажми **Publish**.
5. **Project settings** (шестерёнка) → **Your apps** → значок `</>` (Web). Имя любое, Hosting не нужен.
   Скопируй значения из `firebaseConfig` в `config.js`.

## Шаг 2. GitHub Pages (адрес, по которому откроют друзья)

1. На GitHub создай репозиторий, например `nc-exchange`, публичный.
2. Загрузи в него все файлы из этой папки, кроме папки `dev`.
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
   Через минуту появится адрес вида `https://<ник>.github.io/nc-exchange/`.
4. Вернись в Firebase: **Authentication → Settings → Authorized domains → Add domain** и добавь `<ник>.github.io`.

## Шаг 3. Пригласить друзей

1. Открой адрес, войди через Google, создай группу.
2. Во вкладке «Группа» скопируй ссылку-приглашение и отправь друзьям.
3. Установить как приложение: в Chrome на ПК значок установки в адресной строке; на Android «Добавить на главный экран»; на iPhone в Safari «Поделиться → На экран Домой».

## Как лучше делать скриншот

Открой планшет на вкладке «Рынок» и сделай скриншот целиком, без обрезки (F12 в MTA сохраняет PNG в папку `MTA/screenshots`, ещё подойдёт Win+Shift+S).
Скриншот можно перетащить в окно, выбрать файлом или вставить через Ctrl+V прямо на главном экране.
Цифры, в которых распознавание не уверено, подсвечиваются жёлтым: проверь их перед сохранением.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html`, `style.css` | страница и тёмная тема в стиле NC Exchange |
| `app.js` | экраны: рынок, карточка акции, портфель, группа, окна ввода |
| `store.js` | хранилище: Firebase или демо (localStorage) |
| `ocr.js` | распознавание скриншота (Tesseract.js) и разбор цифр |
| `util.js` | форматирование чисел и расчёт портфеля |
| `firestore.rules` | права доступа в Firebase |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка как приложение и офлайн |

## Помощник для ПК

`download/NCXHelper.exe` — программа в трее: по F9 снимает из окна MTA шапку и карточки
открытого актива и отдаёт их сайту через `http://127.0.0.1:47615`. Распознаёт и сохраняет
сайт (вкладка «Программа для ПК», кнопка «Подключить»). Исходник — `helper/NCXHelper.cs`,
сборка — `helper/build.cmd` (компилятор C# встроен в Windows, ставить ничего не нужно).
Настройки и рамки: `%APPDATA%\NCXHelper\settings.ini`.
